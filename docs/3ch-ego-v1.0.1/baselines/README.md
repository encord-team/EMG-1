# Weak window-label reference baselines

Run `python -B baselines/run.py --root . --check` to recompute scores from the shipped feature table and compare counts and support exactly, and logistic-regression scores within 0.005, with `baselines/metrics.json`. Add `--recompute` on the full extracted layer to re-extract all eligible, one-second, both-wrist GOLD or STANDARD windows from released sensor files. `python -B baselines/extract_features.py --root . --split-file splits/primary_station_day.json` validates the named split and reruns the exact metrics check; the runner also scores the station-held-out split. Training selects a deterministic one-in-20 window subsample by SHA256 of clip ID and start time. Test evaluation uses every eligible window: a window must fit within a quality segment and one vendor segment after a three-second boundary margin, and both wrists must have at least 100 EMG samples. `features.parquet` stores the extracted features and split membership so the scoring command does not need to reread sensors.

Per-class test window counts are tabulated in `baselines/SUPPORT.md`. EMG features are per-channel log mean absolute value, log RMS, standard deviation and log derivative RMS. Band-IMU features are per-axis means and standard deviations; a window with no band-IMU samples receives zero features. The benchmark reports majority, seeded uniform chance, both-wrist EMG, EMG plus band IMU, left-only and right-only logistic regression for both splits. Per-wrist models use the same canonical both-wrist windows, with left features `f0` to `f23` or right features `f24` to `f47`. It reports balanced accuracy, macro-F1, accuracy, per-class support, and 95% bootstrap intervals resampling station-days. A class needs at least 30 test windows and 3 supporting station-days for balanced accuracy and macro-F1; classes below this floor remain in per-class support. Bootstrap draws resample station-days and recompute the score over classes represented in each draw; draws with fewer than two classes are omitted, so an interval can also reflect class absence in this small test set. Sewing-versus-idle AUROC uses the corresponding model probabilities. Labels are weak vendor-derived categories with estimated host alignment. Predicting quality tiers from the sensor values would be circular and is not a benchmark task. The station-held-out split has a failing left band on its test station and head-camera stamp slips on its validation station.

`--recompute` refuses missing sensor files, writes `features.recomputed.parquet`, and compares its table against the shipped `features.parquet`. It never replaces the shipped feature table. Remove the recomputed file after verification.

For a grown release, run `python -B baselines/run.py --root . --recompute --output-dir ../baseline_next` once. It writes both new `features.parquet` and `metrics.json` outside the shipped tree. For a new release, inspect the outputs and regenerate the related documentation before running `--check`. The command does not overwrite current release files.
