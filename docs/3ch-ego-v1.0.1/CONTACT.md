# Contact

Maintainer: Vineeth Velmurugan (Encord).

Send questions, errata, takedown requests and withdrawal requests to support@encord.com. Include the affected clip IDs or object keys when you know them.

- **Questions** about the data, the loader or the documentation go to the same address.
- **Errata:** fixes ship as a new version with a `CHANGELOG.md` entry, not as edits to a released version.
- **Takedown and withdrawal:** affected recordings are removed from later versions.
- **Retention:** released versions stay available unless a withdrawal or legal request requires removal.
