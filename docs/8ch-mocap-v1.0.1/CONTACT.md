# Contact

EMG-1 8-channel v1.0.1 is maintained by Vineeth Velmurugan at Encord.

Send questions, errata reports, takedown requests and withdrawal requests to support@encord.com. Please name the dataset and version (EMG-1 8-channel v1.0.1) and, where it applies, the affected take paths, for example `OP-001/s003/02`.

- Errata: fixes ship as new versions with a `CHANGELOG.md` entry.
- Withdrawal: after a withdrawal request, the affected recordings are removed from later versions.
- Retention: released versions stay available unless a withdrawal or legal request requires removal. Copies that people have already downloaded cannot be recalled.
